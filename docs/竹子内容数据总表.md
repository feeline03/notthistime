# 竹子内容数据总表
 
## 用途
 
这是唯一需要持续维护的原始数据表。
 
- Claude 的“内容创作助手数字人”项目可直接使用这份文件
- Codex 的封面 skill 也可以基于这份文件做复盘和封面判断
- `account-baseline.md` 只是阶段性结论，不是日常维护表
## 更新规则
 
- 每发布一篇内容，新增一行
- 同一篇内容跨平台发布，尽量共用同一个 `内容ID`
- 小红书封面判断优先看 `小红书曝光`、`小红书观看`、`小红书封面点击率`
- 抖音开头判断优先看 `抖音2秒跳出率`、`抖音5秒完播率`、`抖音完播率`
- `价值评论` 只保留最有代表性的 3 到 5 条，优先记录真实场景、真实反驳、真实失败经验
- `备注` 只记关键变量，不写长篇分析
